# 云栖杂货铺｜售后进度查询与客诉处理指引

> **声明**：本文为虚构店铺示例文档，仅供技术演示与知识库测试使用，不构成任何真实商户承诺。

## 一、售后单状态含义

| 状态 | 说明 |
|------|------|
| 待审核 | 已提交申请，客服正在核实 |
| 待寄回 | 审核通过，请按指引寄回商品 |
| 待仓库收货 | 物流运输中，等待仓库签收 |
| 质检中 | 仓库已收货，正在验收 |
| 已完成 | 退款/换货流程结束 |
| 已关闭 | 用户撤销或超时未寄回等原因关闭 |

## 二、换货与维修（示例）

- **换货**：仅支持因质量问题或与描述不符发起的换货；库存允许时将发出同款同规格商品。
- **维修**：部分数码或家电类商品在保修期内可申请维修指引；本演示文档不包含真实保修网点信息。
- 寄回时请附纸条写明订单号与问题描述，避免与其他包裹混淆。

## 三、发票说明（简化）

- 用户可在订单完成后在线申请电子发票（演示场景）；开票内容为「商品明细」或「大类」，以申请页可选为准。
- 发票一经开具，抬头税号修改需在税法允许范围内联系客服处理（演示中略）。
- 个人抬头与企业抬头的开具字段不同，请下单时谨慎填写。

## 四、纠纷升级与反馈时效

- 一般咨询与售后申请：工作日 48 小时内响应（大促期间可能延长）。
- 对处理结果有异议：可通过订单详情页的「申诉」入口补充说明，由店铺二次复核。
- 严重纠纷（演示）：建议保留聊天记录、订单截图、物流凭证，便于核查。

## 五、投诉渠道说明（虚构）

- **在线客服**：店铺 App / 网页右下角入口，服务时间 9:00～21:00（演示）。
